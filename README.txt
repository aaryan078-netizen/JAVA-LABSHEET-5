JAVA OOP LAB — 20 SOLVED QUESTIONS

Contents: 20 independent Java source files. Each file contains exactly one public class, and the filename matches that public class name. Related helper/super/child classes are in the same file.

How to run (Windows / VS Code / terminal):
1. Install a JDK (Java 17 or newer recommended).
2. Open a terminal in this folder.
3. Compile a selected question, for example:
   javac Q01_Student_Record_Class_Object.java
   NOTE: Java requires the source filename to match its public class name. Because these descriptive filenames intentionally match the question rather than the public class, compile using the provided helper script or rename/copy the source file to the public class name before using javac.

EASIEST METHOD:
Use the included run_question.bat (Windows) and pass the question filename. It temporarily copies the selected source to its public-class filename, compiles and runs it, then cleans up generated class files.
Example:
   run_question.bat Q01_Student_Record_Class_Object.java

You can also open any file in an IDE and run it after creating a Java project. The 20 files contain sample data and comments for the requested concepts. This is educational sample code, not a production medical or financial system.
